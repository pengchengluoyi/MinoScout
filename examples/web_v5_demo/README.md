# V5 受控场地

运行 `python server.py --port 8765`，入口为 `http://127.0.0.1:8765/login`。
页面只有主 page，登录通过固定业务标记和身份文本验证，不依赖 URL 改变。
账号 `demo`、密码 `demo-valid` 是公开示例数据；不要输入真实凭据。

`GET /state` 返回累计真实提交、交互与有效登录计数。每个 POST `/submit` 均累加，
不根据请求键去重；复位不清空累计次数，验收使用前后差值。
页面提供同意复选框、受控延迟、重复目标与历史页，用于正常/错误/必填、
SPA 标记、超时、歧义定位和 Web IME/BACK 场景。

首批文字三列场景：

| 前置 | 操作 | 预期 |
| --- | --- | --- |
| 未登录示例场地 | 输入示例账号和正确示例密码，勾选同意，点击登录 | 登录成功标记可见，身份等于 demo-user |
| 未登录示例场地 | 输入示例账号和错误示例密码，勾选同意，点击登录 | 错误提示文本等于账号或密码错误 |
| 未登录示例场地 | 留空账号，勾选同意，点击登录 | 错误提示文本等于账号不能为空 |
| 未登录示例场地 | 输入示例账号和错误示例密码，勾选同意，点击登录 | 登录成功标记可见（裁判反例，必须 verified_fail） |

实际导入仍走既有三列解析器、已配置能力目录与编译模型；这张表不是手写计划入口。
